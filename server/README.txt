まんがビューワー サーバー (exe版)

1. このフォルダを好きな場所に置く(例 C:\MangaViewerServer)。Pythonのインストールは不要です。
2. MangaViewerServer.exe をダブルクリック。初回はデスクトップのショートカットとログイン時の自動起動が作られ、アプリの窓が開きます。
3. 初回の設定画面で、マンガの入っている共有フォルダ(例 \\nas\nas\manga)を選びます。
4. 「Windowsセキュリティの重要な警告」が出たら「アクセスを許可する」を押してください(スマホ・他のPCから使うために必要)。

更新: 設定画面の「アップデート」から手動で、または起動時に自動で更新されます。
RAR/7Zの展開用に 7-Zip を同梱しています(tools フォルダ)。
